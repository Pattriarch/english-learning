# Задачи проекта

Обновлено 11 сентября 2026 года. Сейчас пользователь просит **только дизайн, мобильный интерфейс, выпадающие списки и быстрое изучение слов**. Остальные направления отложены. Генерация новых книжных глав отменена пользователем и остановлена; автоматически её не возобновлять.

## Текущая работа

- [x] Доработать выбранный дизайн в направлении Drinkit: типографику, размеры, отступы, карточки и светлую/тёмную темы. Проверить реальные страницы, включая урок, повторение, словарь и план дня.
- [x] Пройти мобильные размеры: навигацию, длинный текст, формы и аудиоплееры; устранить горизонтальный скролл и перекрытые элементы.
- [x] Исправить выпадающие списки: размеры, контраст, обрезание меню, управление касанием и клавиатурой.
- [x] Сделать быстрый режим словаря в духе Anki: карточка с контекстом, раскрытие ответа, свайпы и равноценные кнопки; сохранить прогресс и интервалы, защитить от случайной повторной оценки.
- [x] Проверить выпуск интерфейса и сохранить его в `main`. Статические файлы уже подхватывает основной сервер 8777; профиль не заменялся, проверки оценок карточек шли в отдельном профиле 8788.

Интерфейс проверен в браузере на ширинах 320 и 390 px, а также на настольном размере. Проверка настоящего телефона, его экранной клавиатуры и разрешений микрофона остаётся отдельным пунктом ниже. Краткое руководство: [HOW-IT-WORKS.md](HOW-IT-WORKS.md).

- [ ] Great Writing и Viewpoint: при возобновлении закрывать конкретные замечания к содержанию и покрытию исходных учебных пунктов, а не только формат JSON. Изолированная проба автора Astra для Great Writing 1, unit 5 отменена и не дала принятого результата; не объявлять её сравнением качества моделей.

Без запуска моделей текущее состояние можно проверить так:

```text

```

На момент остановки результат: `reviewed: 13, missing: 46, complete: false`. Без `--audio-registry` получается другая версия источников Clear Speech; это не потеря сохранённых проверок.

## Отложено: материалы и учебные возможности

- [ ] Если нужен вход с отдельного телефона — настроить доступ к серверу на компьютере или защищённое размещение; текущий сервер слушает 127.0.0.1. Проверить реальные iOS/Android: экранную клавиатуру, запись/распознавание голоса, воспроизведение и свайпы.
- [ ] При необходимости закрепить выбранную модель проверки в настройках; сейчас Codex CLI использует модель по умолчанию. Согласовать баланс качества, скорости и лимитов до изменения.

- [ ] Изображения: расширять набор под конкретный смысл и предложение, с проверяемой привязкой; не подставлять одну общую иллюстрацию как объяснение всех значений слова.
- [ ] Viewpoint: при возвращении к этому курсу добавить отсутствующие **аудио/видео Viewpoint 1**. Сейчас есть сценарии, но нет самих записей. **Viewpoint 2 представлен только Workbook**; для полного курса потребуются Student’s Book и соответствующие материалы. У Clear Speech есть Student Audio CD, а не полный Classroom Audio.
- [ ] Произношение: отдельно спроектировать и проверить оценку реального звучания на записях учащегося. Текущие распознавание речи и проверка текста не измеряют надёжно качество звуков, ударения и интонации.
- [ ] Дальнейшее расширение курса: добавлять только конкретные отсутствующие навыки/практику после аудита текущего маршрута, сохраняя связанные книги как альтернативные источники. Не увеличивать обязательный маршрут повторяющимися темами.
- [ ] Кинокурс за пределами первого сезона: делать отдельным объёмом со своими подготовленными заданиями, контекстами и проверенными медиа; не считать наличие ссылки на субтитры готовым уроком.
- [ ] При необходимости облачного переноса — отдельно реализовать синхронизацию профиля и медиа с обработкой конфликтов. Сейчас JSON-экспорт и снимок для Git не являются автоматической облачной синхронизацией.
- [ ] Проверять рост навыков по самостоятельному письму, разговорам, пониманию новых материалов и применению после паузы. Не обещать достижение C2 или полное владение языком по числу пройденных уроков и карточек.

## Что сохранять при переносе компьютера

- Личный профиль: `app/data/studio/progress.json`, его резервную копию и `app/data/studio/media/`. JSON-экспорт не содержит сами изображения и записи. Настройки могут содержать ключи; не добавлять профиль и ключи в публичный Git.
- Для воспроизведения Clear Speech — приватную папку `app/data/book-recordings/` с 82 MP3. Сервер сначала использует её, затем исходные зарегистрированные файлы в `книги/`, если кеш отсутствует. Git хранит реестр, но не эти записи.
- Для уже опубликованных 872 текстовых уроков — `app/content/book-lessons/` вместе с `app/content/book-release.json`; исходные PDF для обычного чтения не нужны.
- Для повторного разбора и выпуска новых глав — исходные книги, приватные страницы/OCR и сопоставленные материалы `app/data/new-coursebooks/`, а также точные запросы, ответы и проверки `app/data/new-coursebook-lessons/`. Один Git-клон не восстанавливает эти приватные исходники и доказательства.

Старые формулировки «59 глав готовятся» в README/инструкциях описывают состояние до отмены. При следующем обновлении документации заменить их фактическим статусом, сохранив различие между 872 опубликованными уроками и 13 приватно принятыми новыми главами.
