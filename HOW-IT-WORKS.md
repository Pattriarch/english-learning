# Как устроен English

Актуально на 11 сентября 2026 года. Основное приложение: **http://127.0.0.1:8777/**. Порты 8785–8788 использовались для тестовых профилей; это другой прогресс.

## Как заниматься

1. **Сегодня** — план с чередованием новых тем, повторения, чтения/слушания и собственной речи. Открывай следующий блок; результаты упражнений учитываются автоматически, самостоятельную работу отмечай сам.
2. **Программа** — последовательность A1–C2. В уроке сначала разбираешь смысл конструкции, затем пишешь или произносишь свой ответ и изучаешь обратную связь.
3. **Слова → Учить по карточкам** — короткий подход до 20 подготовленных примеров по выбранным фильтрам. EN → RU тренирует понимание, RU → EN — воспроизведение. Вспомни, раскрой ответ, оцени память. Свайп влево означает «Ещё раз», вправо — «Помню». Есть кнопки, пробел и клавиши 1/2/3. Полный разбор необязателен на каждом повторении.
4. **Карточки** — сохранённые фразы возвращаются по расписанию. «Ещё раз» назначает повтор через 10 минут; успешные оценки увеличивают интервал. Это самооценка, а не проверка правильности ИИ. Быстрый подбор берёт один готовый пример на подборку, остальные значения доступны в статье.
5. **Мои мысли** — напиши по-русски, укажи адресата и ситуацию, получи американскую формулировку и объяснение. Можно сначала написать свой английский вариант, сохранить мысль и записать собственный голос.

## Куда уходит написанное

В полях ответа можно **набирать текст или нажать «Надиктовать ответ»**. Говори по-английски, останови запись, проверь появившуюся расшифровку и отправь её на разбор. Это доступно в обычных и книжных уроках, свободной практике, проектах, заданиях произношения, закреплении, разговорах и собственной практике словаря. Диктовка заполняет то же поле и сохраняет тот же черновик. Для устного этапа проекта используется отдельная кнопка «Записать устный ответ», сохраняющая аудио.

Приложение — веб-интерфейс HTML/CSS/JavaScript и локальный сервер Go (`app/english.exe`). Учебный материал уже находится в `app/content/`; чтение не требует нового запроса к модели.

- При наборе текста черновик сразу сохраняется в `localStorage` браузера. После паузы около 600 мс он отправляется локальному серверу. При потере связи остаётся в браузере и повторно отправляется после восстановления соединения.
- Ответы, разборы, карточки, история повторений, планы и черновики хранятся в **`app/data/studio/progress.json`**. Сервер записывает новый файл через временный и сохраняет предыдущую версию в **`progress.json.bak`**.
- Изображения и голосовые записи находятся отдельно в **`app/data/studio/media/`**. JSON не содержит сами медиафайлы. Для переноса копируй весь профиль, а не только JSON.
- **Настройки → экспорт** даёт JSON прогресса. Снимок для Git — отдельное действие; автоматической облачной синхронизации и автоматического push личных ответов нет.
- Настройки подключения находятся в `app/data/studio/settings.json`. Профиль, исходные книги и ключи исключены из обычного коммита приложения.

## Кто проверяет и что расходует лимит

В основном профиле сейчас выбран **Codex CLI** с входом через **ChatGPT**. Поле модели пустое: приложение не фиксирует конкретную модель, а оставляет выбор по умолчанию установленному CLI. Для запроса оно задаёт `reasoning_effort=medium`. Называть конкретную GPT-модель без её явной настройки было бы неточно.

Кнопки перевода, разбора своего варианта и проверки задания отправляют модели задание, соответствующий контекст и твой текст. Она возвращает структурированный разбор: смысл, ошибки, объяснения на русском и английские примеры. Свободные перефразировки допустимы; эталон не используется как единственная допустимая строка. Разбор сохраняется локально. На проверке текст передаётся OpenAI, хотя файл прогресса остаётся на компьютере.

Такие запросы используют **лимиты Codex твоей подписки ChatGPT**. Это не отдельный бесплатный ИИ внутри English. При входе через API-ключ действует отдельная тарификация API: [официальная документация входа](https://learn.chatgpt.com/docs/auth), [лимиты и оплата](https://learn.chatgpt.com/docs/pricing).

Готовые уроки и словарные объяснения, ввод черновика, план и оценки карточек **не вызывают ИИ и не расходуют этот лимит**. Озвучка использует локальный Kokoro; для диктовки настроен локальный Whisper (`127.0.0.1:8080`). Они требуют работающих локальных компонентов. Распознанный текст затем можно отправить на языковую проверку; такая проверка не измеряет качество произношения.

Сервер слушает локальный адрес компьютера. Для телефона настроен HTTPS-доступ через ngrok с отдельным паролем; компьютер и туннель должны работать. Данные остаются в том же профиле на компьютере. Микрофону нужно разрешение браузера. Настройки туннеля и его секреты хранятся вне репозитория. Отложенные задачи перечислены в [TODO.md](TODO.md).
