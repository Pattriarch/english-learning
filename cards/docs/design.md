# English Cards — скрин → карточка Anki

Дата: 2026-08-29. Статус: одобрено.

## Цель

Скриншот с английской фразой падает в папку → демон сам распознаёт фразу,
переводит, генерит пример, ищет картинку и создаёт карточку в Anki.
Ноль ручных действий; журнал для контроля брака.

## Архитектура

Один Go-бинарник `englishd`, исходники в `~/Desktop/english/cards/` (Go-модуль
там же, корень проекта не засоряется). Автозапуск — launchd-агент
(`install.sh` собирает бинарник и ставит plist). Конфиг `config.json` рядом с
бинарником; ключи также берутся из env `ANTHROPIC_API_KEY` / `UNSPLASH_ACCESS_KEY`.

Доступ к Claude — по учётке, а не по ключу: `ant auth login` кладёт OAuth-профиль
в `~/.config/anthropic/`, и SDK находит его сам. Поэтому `anthropic_api_key`
необязателен, а пустой `option.WithAPIKey` в клиент не передаётся — он перебил бы
цепочку поиска учётки внутри SDK. Наличие профиля проверяется функциями самого
SDK (`config.ListProfiles`), чтобы не разойтись с ним в `ANTHROPIC_CONFIG_DIR`
и `XDG_CONFIG_HOME`.

## Поток данных

1. Вотчер (fsnotify) следит за `inbox/`; при старте — пересканирование
   (скрины, упавшие пока демон лежал, не теряются).
2. Новый PNG/JPG/WebP → один вызов Claude API (`claude-sonnet-5`, vision).
   Строгий JSON: `phrase`, `translation_ru`, `example_en`, `example_ru`,
   `image_query`. Несколько фраз на скрине → берётся главная
   (выделенная/центральная).
3. Unsplash по `image_query` → первая картинка (small), сохраняется в `data/media/`.
4. AnkiConnect (`127.0.0.1:8765`): `createDeck` (идемпотентно) →
   `storeMediaFile` → `addNote` в колоду `English`, тип Basic.
5. Скрин → `inbox/processed/`, запись в журнал `data/journal.json`.

## Карточка (Basic)

- **Front:** только фраза EN.
- **Back:** перевод фразы + пример EN + перевод примера + картинка.

Картинка на обороте сознательно: на лице она подсказывала бы смысл.
Пример тоже на обороте вынужденно: Anki считает дубликаты по хешу первого поля,
а пример Claude генерит каждый раз новый — с примером на лице одна и та же фраза
заводилась бы дважды.

## Отказы

- **Anki закрыт / сеть** → запись остаётся в статусе `pending` (все данные уже
  в журнале), ретрай раз в 60 с. Claude повторно не вызывается.
- **Unsplash пусто/упал** → карточка без картинки, не блокер.
- **Claude не нашёл фразу** → скрин в `inbox/failed/`, статус `failed`,
  причина в журнале; кнопка «переобработать».
- **Дубликат** (Anki отклонил по Front) → статус `duplicate`, не ошибка.
- Ошибка Anki API кроме дубликата → `failed` (ретраи бессмысленны).

## Журнал

`http://localhost:8787` — последние карточки: фраза, перевод, миниатюра,
статус (created / pending / failed / duplicate / deleted). Кнопки: удалить
(deleteNotes в Anki), переобработать failed. Один встроенный HTML-шаблон без
сборки. Хром ахроматичный (правило цвета из прошлого проекта).

## Конфиг (defaults)

```json
{
  "anthropic_api_key": "",
  "unsplash_access_key": "",
  "inbox_dir": "~/Desktop/english/cards/inbox",
  "data_dir": "~/Desktop/english/cards/data",
  "deck": "English",
  "model": "claude-opus-5",
  "journal_port": 8787,
  "ankiconnect_url": "http://127.0.0.1:8765"
}
```

## Тесты

- Парсинг ответа Claude (фенсы, поле error, пустая фраза).
- Клиент AnkiConnect на httptest-моке (успех, дубликат, ошибка API).
- Журнал: save/load roundtrip.
- Вотчер — интеграционно руками.

## Вне скоупа

Мобильный вход, шаг подтверждения, TTS, свои интервалы повторения
(этим занимается Anki).
