Whisper и озвучка на своём компьютере

Whisper превращает запись в текст и возвращает время и уверенность слов. Kokoro читает английские фразы американским голосом. После установки модели работают локально.

Mac

  1. Установи Go 1.25+, Python 3.12 и инструменты Apple: xcode-select --install. С Homebrew: brew install go python@3.12.
  2. В папке приложения один раз открой Install-Speech.command. Скачиваются модели и собирается Whisper. На Apple Silicon используется Metal; на Intel — CPU.
  3. Открой Start-English.command. Если macOS блокирует скачанный скрипт, запусти его из Terminal: bash Install-Speech.command, затем bash Start-English.command.

Windows с NVIDIA

Нужны Go 1.25+, Python 3.12+, Visual Studio Build Tools с компонентом «Desktop development with C++» и CUDA Toolkit. Установи их, затем открой Developer PowerShell for VS и перейди в папку приложения:

powershell -ExecutionPolicy Bypass -File app/scripts/install-local-whisper.ps1 -Accelerator cuda
powershell -ExecutionPolicy Bypass -File app/scripts/install-local-kokoro.ps1

После установки открой Start-English.cmd. Если CUDA недоступна, вместо cuda выбери cpu.

Подключение и практика

Лаунчер добавляет адрес готового Whisper, если поле ещё пустое. Иначе укажи адрес вручную и нажми «Проверить Whisper»:

http://127.0.0.1:8080/inference

Если у тебя уже есть whisper.cpp server, запусти его на этом адресе с английской моделью. Нужна свежая версия с verbose_json и вероятностями слов. Один скачанный файл модели или библиотека faster-whisper ещё не являются HTTP-сервером.

В заданиях и шаге «поговорить» раскрой «Повторить образец и проверить слова»: послушай фразу, запиши повторение и останови запись. Видны пропуски, замены, лишние слова и «проверь произношение». Обычная запись своего ответа показывает расшифровку без сравнения с единственным образцом.

Низкая уверенность может быть вызвана шумом. Совпавшие слова не гарантируют правильные th, гласные или интонацию: подсказки помогают повторить трудный звук, но Whisper не выполняет фонетический разбор.

Если не запускается

Посмотри app/data/local-whisper/server.stderr.log или app/data/local-kokoro/server.stderr.log. Если порт занят, лаунчер сообщает об этом и сохраняет работающие процессы. Микрофон разреши для 127.0.0.1 в браузере. Если сервер не передал вероятности слов, останется сравнение расшифровки.
