Подключить свой аккаунт ChatGPT

English использует официальный Codex CLI как помощника. Он проверяет ответы, объясняет ошибки по-русски и ведёт диалоги. Whisper распознаёт речь локально; помощнику отправляются текст ответа и контекст задания.

  1. Если Codex уже установлен и вход выполнен, выбери в настройках «Мой аккаунт ChatGPT · Codex».
  2. Если ещё не входил: на Mac открой Connect-ChatGPT.command в корне репозитория. Или выполни в Terminal / PowerShell codex login и заверши вход в открывшемся браузере.
  3. Нажми «Проверить вход ChatGPT». Затем «Проверить подключение»: это короткий запрос к модели, который расходует часть доступного лимита.

Если Codex CLI ещё нет

Установи Node.js LTS, затем:

npm install -g @openai/codex
codex login
codex login status

После установки CLI перезапусти English. На Mac лаунчер также находит CLI из установленного ChatGPT. Модель можно оставить пустой: будет выбрана модель Codex по умолчанию.

Аккаунт и API-ключ

Для входа через аккаунт не нужно вставлять токен браузера или cookie. Вход и обновление авторизации выполняет Codex. English не читает файл токенов и не показывает секреты.

Поле API-ключа в варианте «Совместимый API» — другой способ: ключ OpenAI Platform, базовый адрес https://api.openai.com/v1 и доступная API-модель. Запросы API оплачиваются отдельно от подписки ChatGPT.

Сам факт входа не гарантирует доступ к любой модели или свободный лимит. Если проверка сообщает об исчерпанном лимите, дождись восстановления или выбери другой настроенный сервис. Готовые уроки, фото и локальная речь остаются доступны.
