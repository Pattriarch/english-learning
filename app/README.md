# English

Мастерская американского английского A1–C2. Основной маршрут содержит 163 занятия с 1 065 заданиями; 22 обзорных занятия доступны отдельно для закрепления. Также доступны 872 уникальных книжных урока, 24 проекта и контрольные, 30 занятий кинокурса Better Call Saul и шесть дизайнов. Готовность 872/872 подтверждена проверкой книжного выпуска. Карта результатов, разговорная практика, тетрадь собственных мыслей, отложенное применение и контекстный словарь включены в основной интерфейс.

Полные словарные разборы готовы для всех 18 534 активных контекстов: значение, перевод, сочетаемость, ошибки и собственное применение. Объём выпуска проверяется по `content/lexicon/full-analysis.json` и показан в словаре. Дополнительные 59 глав из новых книг проходят отдельную подготовку и проверку; разбор исходных страниц сам по себе не означает готовность урока.

Из корня запустите `Start-English.cmd`. Или из этой папки:

```sh
go run -mod=readonly ./cmd/english
```

Адрес: http://127.0.0.1:8777. Прогресс: `data/studio/progress.json`.
