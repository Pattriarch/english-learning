# ENGLISH OUTPUT TRAINER

Личная система тренировки американского английского. Две половины:

**Telegram-бот** — ежедневное письмо. Пишешь на английском, чего не знаешь — вставляешь
по-русски. Бот разбирает: ошибки с привязкой к темам справочника, «правильно, но американец
скажет иначе», перевод русских вставок, сленг-бонус. Всё стоящее падает в очередь карточек Anki.

**Сайт-тренажёр** (localhost:8777) — справочник по оглавлениям Murphy / Phrasal Verbs /
Collocations / Vocabulary in Use плюс сборные темы современного сленга. У каждой темы
два независимых прогресса:

- **применяю в письме** — считается из твоих писем в боте;
- **изучил в тренажёре** — считается из упражнений.

Знать тему и пользоваться темой — разные вещи, поэтому и показываются они рядом.

## Форматы упражнений

| формат | что это |
|---|---|
| **Дело №…** | детектив Мия Торрес, Чикаго. Грамматика — улика: неверное время выдаёт лжеца |
| **Тред** | переписка в мессенджере. Выбираешь реплику: натуральная / кривая / «учебниковая» |
| **Дубляж** | ты переводчик сериала: русская реплика → твой английский → эталон и разбор |
| **Радар** | блиц по 7 секунд: «звучит по-американски или нет». В пуле — кальки и британизмы |
| **Чужое письмо** | письмо с 6-10 спрятанными ошибками по теме. Кликаешь подозрительное |

## Запуск

```bash
cp .env.example .env      # вписать TELEGRAM_TOKEN
./start.command           # или: go run ./cmd/english
```

Разбор писем по умолчанию идёт через локальный `claude` — то есть на твоей подписке
Claude Code, API-ключ не нужен. Работает, пока `claude` залогинен (`claude` в терминале
покажет). Если ключ всё же удобнее — `LLM_PROVIDER=api` плюс `ANTHROPIC_API_KEY`.

Сайт: http://localhost:8777. Бот поднимается сам, если задан `TELEGRAM_TOKEN`;
без него работает только сайт.

## Переменные окружения

| переменная | по умолчанию | зачем |
|---|---|---|
| `LLM_PROVIDER` | `cli` | `cli` — разбор через твою подписку, `api` — через ключ |
| `ANTHROPIC_API_KEY` | — | нужен только при `LLM_PROVIDER=api` |
| `CLAUDE_MODEL` | `sonnet` | алиас для cli, полный id для api |
| `CLAUDE_BIN` | `claude` | путь к бинарю, если он не в PATH |
| `TELEGRAM_TOKEN` | — | без неё бот не стартует |
| `TELEGRAM_CHAT_ID` | — | если задан, бот отвечает только тебе |
| `BOT_USERNAME` | — | имя бота для кнопки «Написать письмо» на дашборде |
| `PORT` | `8777` | порт сайта |

## Команды бота

- `/write` — тема дня, дальше просто пишешь письмо ответом
- любой текст длиннее 200 символов — тоже разбирается как письмо
- `/anki` — файл TSV со всей очередью карточек (импорт в Anki руками)
- `/stats` — стрик и темы, где ты стабильно ошибаешься
- `/topics` — сводка по каталогу

## Контент

- `content/topics.json` — каталог тем, собран по реальным оглавлениям книг из `content/toc/`
- `content/lessons/<topicId>.json` — уроки. Схема: `content/LESSON_SCHEMA.md`,
  эталон качества: `content/lessons/egiu-013.json`
- Темы без урока в каталоге всё равно видны и накапливают прогресс использования из писем.

Добавить урок = положить новый JSON по схеме в `content/lessons/`. Перезапуск не нужен —
уроки читаются с диска по запросу.

## Устройство

Go 1.25, один бинарь: HTTP-сервер отдаёт SPA и API, бот работает long polling в горутине.
SQLite (`data/english.db`, cgo не нужен). Фронт — vanilla JS без сборки, правится на живую.

Проектные решения и модель данных: `docs/DESIGN.md`.
