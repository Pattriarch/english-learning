# Точная схема урока (content/lessons/<topicId>.json)

Обязательна для фронта (рендереры), контент-агентов и моков. Эталон: lessons/egiu-013.json.

```json
{
  "topicId": "egiu-013",
  "title": "Present perfect vs past simple",
  "title_ru": "уже сделал vs сделал тогда",
  "theory": "markdown-строка",
  "scenes": [ /* 2–4 сцены разных типов, схемы ниже */ ]
}
```

## type: "case" — детектив

```json
{
  "type": "case",
  "caseTitle": "Дело №7: Пропавший коммит",
  "intro_ru": "сеттинг, 1-3 предложения",
  "steps": [{
    "narrative": "markdown: RU-нарратив, EN-реплики героев внутри выделены **жирным**",
    "question_ru": "вопрос детектива к тебе",
    "choices": ["вариант 0", "вариант 1", "вариант 2"],
    "answer": 0,
    "clue_ru": "почему грамматика — улика (показывается после ответа)"
  }],
  "outro_ru": "развязка дела"
}
```

## type: "thread" — мессенджер

```json
{
  "type": "thread",
  "contact": {"name": "Jake", "emoji": "👨‍💻", "desc_ru": "твой техлид, Остин"},
  "intro_ru": "контекст переписки",
  "steps": [{
    "incoming": ["пузырь собеседника 1", "пузырь 2 (опц.)"],
    "options": [
      {"text": "реплика", "verdict": "natural", "note_ru": "почему так говорят"},
      {"text": "реплика", "verdict": "error", "note_ru": "в чём грамм. ошибка"},
      {"text": "реплика", "verdict": "textbook", "note_ru": "правильно, но так не говорят"}
    ]
  }],
  "outro_ru": "чем кончилась переписка"
}
```

`natural` — единственный «правильный» выбор. Порядок options перемешивает фронт.

## type: "dub" — дубляж

```json
{
  "type": "dub",
  "show_ru": "«Halsted Street», s02e05 — что за сцена",
  "steps": [{
    "scene_ru": "описание кадра",
    "line_ru": "русская реплика для перевода",
    "reference": "эталонный AmE",
    "alt": "допустимый второй вариант или null",
    "note_ru": "разбор: почему эталон такой"
  }]
}
```

Самооценку (совпал/близко/мимо) рисует фронт, в данных её нет.

## type: "radar" — блиц

```json
{
  "type": "radar",
  "intro_ru": "правила раунда одной строкой",
  "cards": [{
    "phrase": "I've seen him yesterday",
    "ok": false,
    "fix": "I saw him yesterday",
    "flash_ru": "yesterday — метка прошлого, перфект запрещён"
  }]
}
```

`ok: true` → `fix` опускается. 10–15 карточек. В пуле: ошибки рус. спикеров, британизмы
(помечать в flash_ru: «британское, в США скажут …»), кальки, и нормальные фразы для баланса.

## type: "letter" — чужое письмо

```json
{
  "type": "letter",
  "from_ru": "кто пишет, кому, зачем — 1-2 предложения",
  "segments": [
    {"text": "Hey, I "},
    {"text": "have talked", "error": true, "fix": "talked", "note_ru": "почему"},
    {"text": " to the landlord yesterday."}
  ],
  "corrected": "полный исправленный текст письма"
}
```

Сегменты конкатенируются в текст письма как есть (пробелы внутри text).
Кликабельны ВСЕ сегменты длиной >2 слов не считая error-сегментов — фронт сам решает,
данные только помечают error-сегменты. 6–10 ошибок на письмо, все — по теме урока.
