# English

Локальное приложение для самостоятельной практики английского A1–C2. Основной маршрут: 163 занятия и 1 065 заданий; ещё 22 обзорных занятия доступны отдельно для закрепления, а 30 занятий относятся к киноклубу. Книжные главы считаются отдельно: базовые 872 опубликованы, дополнение из 59 глав новых книг готовится. Текущая доступность каждого книжного выпуска показывается в библиотеке и карте обучения.

## Запуск

На Windows дважды нажмите `Start-English.cmd` в корне репозитория. Скрипт соберёт приложение, запустит сервер в фоне и откроет http://127.0.0.1:8777. Повторный запуск открывает работающий экземпляр.

Нужен Go 1.25+ либо ранее собранный `app/english.exe`. Node/npm для самого приложения не нужны. Из терминала:

```sh
cd app
go run -mod=readonly ./cmd/english
```

Сервер использует стандартную библиотеку Go. `-mod=readonly` обходит неполный каталог vendor и не разрешает команде изменять go.mod или go.sum. Сторонние зависимости в существующем go.mod относятся к сохранённым старым модулям.

Порт: `--addr 127.0.0.1:8778`. Другой профиль: `--data data/another-profile`. Команды выполняются из `app`. Сервер предназначен для loopback-доступа.

## Цикл занятий

1. **Сегодня**: сбалансированный план на выбранное время.
2. **Программа A1–C2**: 167 подготовленных занятий и 972 задания с самостоятельным ответом. Из них 118 уроков маршрута по уровням, 19 исходных и 30 по сериалу. Объяснения разбирают смысл конструкции, её устройство, контрасты и ошибки. В новой программе теория составляет около 250–300+ слов на главу плюс примеры и задания.
3. **Практика**: письмо, разговор, чтение, аудирование, активный словарь, перевод мысли. «Новая ситуация» создаёт дополнительные задания по интересам. После ответа можно продолжить разговор по вопросу помощника.
4. **Медиатека**: местное видео, SRT/VTT, повтор реплики, пауза после фразы, кадр, скриншот и OCR.
5. **Повторение**: русский смысл → английский ответ по памяти → открытие оборота → самооценка.
6. **Мой прогресс**: активное время, баланс форматов, оригинальные ответы и разборы. Ошибку можно сохранить в карточку.

Рабочий цикл: понять объяснение → ответить самостоятельно → изучить разбор → переписать проблемное место → применить конструкцию в своей истории → повторить позже.

«Пройдено»: выполнены все упражнения темы, не менее 80% последних ответов верны. Это прогресс практики, не независимая диагностика CEFR. Теория, прочитанная без упражнений, отмечается отдельно.

## Помощник

В текущем окружении подключение уже настроено и проверено через **ChatGPT / Codex CLI**. В новом клоне первоначально включён режим без ИИ.

### ChatGPT / Codex

Вызывается официальный `codex exec` с текущим входом через ChatGPT и соответствующими лимитами Codex. Браузерная автоматизация не используется. Процесс работает во временной папке, с read-only sandbox, отключённым shell tool, без загрузки пользовательской конфигурации и постоянной CLI-сессии. Приложение не читает токены из файлов авторизации.

На Windows выбирается свежий CLI из установки настольного Codex, затем — `codex` в PATH. Можно задать `ENGLISH_CODEX_BIN`. CLI должен поддерживать `exec --ignore-user-config --ephemeral`. Установка/вход:

```sh
npm install -g @openai/codex
codex login
```

Модель можно оставить пустой: используется модель CLI по умолчанию. [Авторизация](https://learn.chatgpt.com/docs/auth), [неинтерактивный режим](https://learn.chatgpt.com/docs/non-interactive-mode).

### Ollama

Установите [Ollama](https://ollama.com/) и выполните:

```sh
ollama pull qwen3.5:9b
```

Настройки: Ollama, `http://127.0.0.1:11434`, `qwen3.5:9b`. RTX 3080 Ti 12 ГБ / RAM 32 ГБ — разумная отправная конфигурация для этой модели. Веса занимают около 6,6 ГБ; дополнительная память нужна для контекста. Качество учебного разбора на ней здесь не тестировалось. Ollama и веса автоматически не устанавливались: основным рабочим подключением выбран Codex.

Протокол: `/api/chat`, JSON-ответы, контекст 16384 токена. [Модель](https://ollama.com/library/qwen3.5), [формат ответа](https://docs.ollama.com/capabilities/structured-outputs).

### Claude и API

Claude запускается через `claude -p`, safe mode, без инструментов и постоянной сессии. С 15 июня 2026 автоматические вызовы расходуют отдельные кредиты Agent SDK, а не обычный лимит интерактивной подписки. [Условия Anthropic](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan). Платные запросы Claude при разработке не выполнялись.

Совместимый API: базовый URL с `/v1`, метод `/chat/completions`, `response_format: json_object`. Ключ хранится только в `settings.json`, не возвращается фронтенду и не входит в экспорт прогресса. Для удаления через API передайте ключ `__CLEAR__`. HTTP разрешён только для localhost; удалённому API нужен HTTPS.

Без ИИ распознаются некоторые известные варианты переводов. Остальные ответы сохраняются **без оценки**, потому что они тоже могут быть правильными. Открытые письменные задания без ИИ не оцениваются.

## Тетрадь своих мыслей

В **«Мои мысли»** можно записать собственную мысль по-русски, выбрать адресата и регистр, а затем сначала попробовать выразить её по-английски. Помощник предлагает американскую формулировку и объясняет смысловые решения. После этого доступны воспроизведение без открытого образца и применение в другой ситуации. Эти работы сохраняются отдельно; сам перевод или сохранение заметки не означает успешного переноса навыка.

Черновик сохраняется во время ввода. Разбор связан с той версией исходной мысли, для которой он запрошен: изменение текста, адресата или регистра делает прежний результат историческим. Запоздалый ответ помощника не должен стирать новую версию. Перевод и проверка требуют настроенного помощника; сохранённые заметки доступны без нового запроса.

Диктовка получает текст для проверки. Отдельная запись сохраняет аудиофайл и связь с заметкой в локальном профиле, включая завершение записи при уходе со страницы. Аудио можно прослушать после возвращения; для переноса на другой компьютер нужны и JSON-прогресс, и папка медиа. Проверка транскрипта не оценивает артикуляцию. Подробные ограничения и проверки: [NOTEBOOK-SAVING-REVIEW-2026-09-10.md](NOTEBOOK-SAVING-REVIEW-2026-09-10.md).

## Контекстный словарь

**«Живой словарь»** позволяет искать по слову и контексту, выбирать NGSL/GR/Spoken/NAWL или авторские выражения, фильтровать разобранные темы. В каждой записи видны целое предложение, точная подсветка изучаемой формы, доступный русский перевод и происхождение материала. Значение связано с примером только при явной проверенной привязке; соседние словарные определения остаются справочными.

Отдельно подготовлены **36 выражений в шести сценах**: техническая проблема, командный план, друзья, онлайн-обсуждение, покупка и бюджет бизнеса. У каждого есть авторский контекст из двух предложений, полный перевод, разбор смысла и грамматики, регистр и задание на собственную новую ситуацию. Общие иллюстрации служат ассоциацией со сценой; они не изображают буквально все события каждого примера. Американская опора не означает, что выражение употребляется исключительно в США.

Можно скрыть английский текст, сохранить контекст в повторение и написать или продиктовать собственный ответ. Черновик сохраняется отдельно от исходного примера; после проверки ответ и разбор доступны в журнале. Отметки «Изучаю» и «Узнаю в контексте» — самооценка, а не автоматический уровень CEFR. Наличие десяти тысяч записей также не удостоверяет владение ими.

Текущие размеры и границы подготовки записаны в `content/lexicon/coverage.json`; происхождение и лицензии — в `sources.json`, внутри записей и в [контракте словаря](../content/lexicon/README.md). Эти сведения нужно сохранять при экспорте открытых корпусных и словарных материалов. Методика занятий: [LEARNING-METHOD-RESEARCH-2026-09-10.md](LEARNING-METHOD-RESEARCH-2026-09-10.md).

## Голос

Раздел **Произношение** — 16 занятий от букв и IPA до связной американской речи: русские объяснения постановки звуков, контрастные пары, чтение вслух, озвучивание слов и фраз, запись и скачивание собственного аудио. По умолчанию выбран американский голос; фактически доступный голос и его вариант английского видны в занятии. Основная IPA согласована с американской опорой, британские варианты подписаны как сравнение. Словарные ссылки позволяют сверить отдельное слово с образцом.

Озвучка примеров использует локальный Kokoro и выбранный американский голос. Исторические 224 WAV-образца Zira сохранены в проекте, но текущие кнопки не переключаются на них или SpeechSynthesis при сбое Kokoro. Исходные записи учебника помечены отдельно и воспроизводятся как оригинальное аудио. Нейтральный синтез не изображает гарантированно заданный контур интонации; техническая проверка файла не является акустической оценкой звуков. [Установка и голоса Kokoro](LOCAL-TTS-2026-09-10.md).

Заметки и критерии самопроверки сохраняются в общие черновики; «Отметить практику» сохраняет прохождение в `read` под ключом `pronunciation:<id>`. Это самоотметка выполненной практики. Разбор помощника проверяет текст ответа и понимание темы, явно исключая акустическую оценку произношения. Запись можно скачать; автоматически в JSON звук не включается. Подробности — [PRONUNCIATION.md](PRONUNCIATION.md).

Запись длится до пяти минут, чтобы хватало на развёрнутые задания C1–C2. Прослушайте её и проверьте расшифровку перед разбором. В книжных уроках каждый дубль сохраняется отдельным аудиофайлом в профиле с датой и точной версией задания. После перехода или перезагрузки его можно переслушать; этап переработки показывает записи исходных устных заданий. Записи разных версий заданий не смешиваются. Правка распознавания, ударений или интонационных пометок сохраняет связь с реальной записью; один набранный текст устным ответом не становится.

Раздел «Мои мысли» также сохраняет отдельный аудиофайл и связь с заметкой. В других формах обычной диктовки может сохраняться только текст и разбор, а аудио оставаться на текущей странице. JSON содержит ссылки на записи, но не сами звуковые файлы: для полного переноса нужен весь профиль вместе с `media/`.

- По умолчанию — SpeechRecognition в Chrome/Edge, если поддерживается. Он может использовать сетевой сервис браузера.
- Локальная альтернатива — [whisper.cpp server](https://github.com/ggml-org/whisper.cpp/tree/master/examples/server), адрес `http://127.0.0.1:8080/inference`. Запись преобразуется в моно WAV 16 кГц.
- Примеры озвучиваются через Kokoro; исходные записи учебников воспроизводятся отдельными плеерами.

Разбор расшифровки не является оценкой произношения. Для работы над звуком и ритмом: послушать короткую реплику → повторить → записать себя → сравнить. Реальная микрофонная сессия и внешний Whisper требуют проверки с вашим голосом и установленным сервером.

## Видео, OCR, Anki

Местное видео открывается браузером через object URL и не загружается на сервер. Поддержка кодеков зависит от браузера; обычно удобны MP4/H.264 и WebM. Субтитры: UTF-8 SRT/VTT, многострочные реплики, таймкоды, идентификаторы и настройки VTT.

Для другой вкладки: «Захват вкладки» → источник → «Сохранить кадр». Плеер источника остаётся под вашим управлением. Автоматического скачивания субтитров с YouTube/Netflix нет: импортируйте SRT/VTT или используйте OCR кадра. Защищённое видео может давать чёрный кадр.

Кнопка «Окно захвата» открывает компактное окно рядом с плеером: вставка скриншота, OCR, перевод и сохранение карточки. Его словарь и прогресс общие с основным приложением.

Скриншот: `Win + Shift + S` → `Ctrl + V` в медиатеке → выделить текст → проверить OCR → перевести → сохранить. Windows использует Windows.Media.Ocr с английским языковым пакетом; macOS/Linux — установленный `tesseract` с языком `eng`. Windows OCR проверен и напрямую, и через форму приложения.

Карточки: **Front — русский смысл; Back — английская фраза, объяснение, кадр**. Для прямой передачи откройте Anki с AnkiConnect, код `2055492159`. Создаётся отдельный тип заметки English Workshop. Повторная передача проверяет стабильный тег заметки для восстановления после сетевого сбоя.

«Скачать для Anki» возвращает ZIP: `english.tsv`, `collection.media/`, инструкция. Картинки скопируйте в `collection.media` профиля Anki, затем импортируйте TSV с HTML. [Руководство Anki](https://docs.ankiweb.net/importing/text-files.html).

Встроенные интервалы основаны на SM-2: ошибка → 10 минут; первые успешные ответы → 1 день и 3 дня; дальше интервал зависит от лёгкости. Это отдельное расписание: история повторений с Anki не синхронизируется. AnkiConnect на этой машине не был запущен; реальная отправка в пользовательскую колоду не выполнялась.

## Учебники

Обнаружено 11 PDF. Для B1–B2 достаточно:

- Murphy, English Grammar in Use, Intermediate.
- English Vocabulary in Use, Upper-Intermediate.
- English Collocations in Use, Intermediate.
- English Phrasal Verbs in Use, Intermediate.

Advanced используйте как дополнительный справочник, Elementary — для точечного повторения. Проверены титулы и оглавления основной грамматики, collocations и vocabulary. Некоторые PDF являются сканами: вместо выделения текста используйте скриншот.

Базовый каталог содержит **1 017 записей юнитов из 11 PDF**; после исключения повторного издания Murphy — **872 уникальные главы**. Это главы разных источников, а не 872 непересекающиеся языковые темы. Номера, названия и страницы базовых книг проверены. Предыдущие 208 идентификаторов сохранены для совместимости созданных ранее уроков.

В «Все учебники» можно выбрать книгу, искать по названию/номеру, скрыть прочитанное и включить повторное издание. Подготовленная глава открывает самостоятельное занятие: объяснения, разобранные примеры, задания с полным ответом, модели и русские пояснения. Количество заданий зависит от главы. Уроки с шестью этапами начинают с ещё не пройденной диагностики; теория остаётся доступной. Ответы, черновики, записи и отметки чтения сохраняются в профиле. Чтение не выдаётся за освоение темы.

**Базовый книжный выпуск: 872/872 главы опубликованы.** Отдельные **59 глав** Clear Speech, Great Writing и Viewpoint проходят подготовку и проверку; они не входят в этот показатель полной готовности базы. После публикации всего дополнения книжный набор составит **931 главу**. Фактический текущий статус определяется файлами `content/book-lessons/` и `content/book-release.json`; `/book-content/status.json` отдельно возвращает доступность новых глав по `content/new-coursebooks-intake.json`. Подготовка исходных страниц не равна публикации урока. Книжные главы не прибавляются к 163 шагам основного маршрута как новые непересекающиеся темы.

Готовые опубликованные уроки работают в чистом клоне без PDF, OCR-кеша, изображений исходных страниц и дублирующих файлов `studio/book-content/`: сервер проверяет SHA урока по манифесту и обслуживает содержание из `content/book-lessons/`. Если приватные источники присутствуют, их проверки сохраняются; изменённый источник не обходится доверием к старому манифесту. Открытие самого PDF требует локального файла из папки `книги/`. Синтез примеров после клонирования требует отдельной [установки Kokoro](LOCAL-TTS-2026-09-10.md#установка-после-клонирования); старый `scripts/prepare-book-audio.ps1` создаёт системные WAV и не восстанавливает текущую озвучку.

Новая подготовка и повторная редакция книжного материала — отдельный процесс. Ему нужны локальные учебники, извлечённый текст или OCR и изображения всех относящихся к главе страниц; эти приватные материалы находятся в исключённых из Git папках. Исходные страницы используются для проверки объяснений и тематического покрытия, а не публикуются вместе с авторским уроком. Повторный выпуск `scripts/publish_book_release.py` проверяет связь урока с источниками и обновляет переносимый манифест. Наличие только названия главы не считается доказательством разбора её содержания.

**Папку `книги/` пока сохраняйте:** 59 глав из новых учебников ещё не опубликованы. После их выпуска PDF не понадобятся для прохождения готовых уроков, но останутся нужны для просмотра оригиналов и повторной редакции по источнику. Для 82 MP3 Clear Speech подготовлена отдельная проверенная копия `app/data/book-recordings/`: сервер использует её первой. Эту папку нужно переносить отдельно от Git, чтобы сохранить оригинальную озвучку без исходной папки книг. На новом компьютере копию также можно создать командой `python app/scripts/cache_book_recordings.py`, пока исходные MP3 доступны. В Git книги и записи добавлять не нужно. Рабочий прогресс также переносится отдельно, как описано ниже.

## Маршрут, киноклуб и оформление

Карта A1–C2 содержит контрольные точки уровней, быстрый проход знакомых тем, поиск и недельный план. «Все времена» связывает 12 сочетаний времени/аспекта с отдельными уроками и показывает другие способы говорить о будущем. Девять направлений включают грамматику, лексику, чтение, слух, письмо, разговор, произношение, прагматику и передачу смысла. [Методика и полный план](LEARNING-PATH.md).

Better Call Saul: десять эпизодов первого сезона, тридцать готовых авторских занятий, 150 заданий и 60 выражений для карточек. По каждому эпизоду есть подготовка, слушание, собственный ответ, заметки и план двух вечеров. Найдены публичные страницы английских SRT ко всем 10 эпизодам и ZIP сезона на TVsubtitles; ссылки и проверенные версии доступны в киноклубе и медиатеке. Сам архив не включён в приложение; файл нужно скачать на странице источника и импортировать. Английские CC подтверждены также официальными изданиями. Учебные тексты не выдаются за реплики сериала. Для конкретных таймкодов нужно подключить свои SRT/VTT и видео. [Кинокурс и источники](CINEMA.md).

«Выбрать дизайн» открывает шесть полноценных вариантов с разной компоновкой и двумя темами. Шрифт и обложка хранятся локально. [Варианты и промпт изображения](DESIGN.md).

«Карта навыков» открывается из программы или кнопкой «Темы других программ» в библиотеке. Она содержит 48 практикумов по внешним программам: самостоятельное действие, исходные данные, три критерия и связанные уроки. Восемь практикумов на каждый уровень; основание — 23 первичных источника. Ответы проверяются по заданию и уровню на сервере, сохраняются в журнале и JSON. Задания на передачу смысла могут включать русскую часть; она не считается ошибкой языка. [Внешний аудит](EXTERNAL-CURRICULUM-AUDIT.md), [18 дополнительных уроков](RESEARCH-LESSONS.md).

Медиатека и киноклуб предлагают найденные страницы English-субтитров для всего первого сезона. Для локального SRT/VTT сохраняется сдвиг таймкодов; доступно совмещение реплики с кадром. Добавление кадра к выбранной фразе сохраняет перевод, а запоздалые результаты OCR, перевода и сохранения карточки не стирают новый черновик. [Проверенные источники и условия доступа](SUBTITLE-RESEARCH.md).

## Сохранение и Git

```text
app/data/studio/
  progress.json       ответы, карточки, интервалы, черновики, время, созданные уроки
  progress.json.bak   предыдущая успешная версия
  settings.json       настройки и необязательный API-ключ
  settings.json.bak   предыдущая версия настроек
  media/              изображения и сохранённые аудиозаписи
```

Записи сериализуются и сохраняются через временный файл и замену. При ошибке записи изменение не считается успешным. Черновики дополнительно сохраняются в localStorage.

«Скачать JSON» экспортирует прогресс. «Импортировать» объединяет попытки, карточки и повторения по ID; существующие карточки сохраняют местное расписание, новые — импортированное. Повторный импорт не дублирует записи.

«Снимок для Git» сохраняет `progress/english-progress.json` в рабочей папке. Файл содержит личные ответы и заметки и исключён из обычного Git-добавления; для хранения истории в репозитории используйте отдельный приватный вариант с явным выбором данных. Снимок не включает ключи и медиафайлы: изображения и записи перенесите отдельно папкой `media/`; архив Anki переносит изображения карточек, но не все записи тетради.

Рабочие данные, настройки, логи, бинарники и книги исключены из Git. Приложение не выполняет push и не настраивает облачную синхронизацию. Для восстановления повреждённого JSON при остановленном сервере верните файл `.bak` на место основного.

## Разработка

```sh
cd app
go test -mod=readonly ./...
go vet -mod=readonly ./internal/studio
node --test studio/tests/*.mjs
```

Проверки: программа занятий, отсутствие ложной офлайн-оценки, авторитетное задание на сервере, валидация ответа ИИ, идемпотентность попыток/повторений, параллельное сохранение, перезапуск, импорт, экспорт без секретов, экранирование HTML, origin, SRT/VTT и подсчёт прогресса.

В браузере проверены реальный разбор Codex, верный перевод вне образца, скриншот/OCR, карточка из субтитров, повторение и его перенос на завтра, генерация новой ситуации. Узкий экран проверен на ширине около 390px. Тестовый профиль: `data/qa`, порт 8778.

Проверка расширения A1–C2: Go-тесты и vet прошли; шесть Node-тестов проверяют также ссылки программы, 12 временных форм, все 30 занятий киноклуба и 1017 записей оглавлений. Все шесть дизайнов просмотрены на широком экране и проверены на ширине 390px. В отдельном профиле `data/qa-v2` Codex создал урок из настоящего текста юнита, проверил ответ рабочей тетради и принял правильный перевод C2, отличающийся от эталона. Тестовые ответы не добавлялись в основной прогресс.

Внешнее исследование: после добавления 18 уроков и 48 практикумов прошли полный `go test`, `go vet`, синтаксис JavaScript и восемь Node-тестов. Новые проверки охватывают ссылки на источники/уроки, полноту списка эпизодов и сдвиг таймкодов. В `data/qa-v3` живой Codex корректно проверил русскую передачу сообщения и английское письмо в одном задании. В браузере проверены выбор эпизода, сдвиг 2,5 секунды и его восстановление после перезагрузки, а также ширина 390px. Основной профиль не использовался для тестовых ответов.
