# Фото к готовым урокам

В наборе 116 готовых фотографий для базовых слов A1–A2: к первым 48 добавлены ещё 68. Есть еда, одежда, посуда, комнаты, техника, транспорт и места в городе. Источники — Openverse и Wikimedia Commons; у каждой фотографии сохранены автор, название, лицензия, исходная страница и SHA-256. Это найденные фото, генерация не использовалась. Около 16,1 МБ, до 960 px, без обрезания кадра.

Файлы лежат в `app/studio/assets/words/`. Манифест — `manifest.json`. Лицензии CC BY, CC BY-SA и CC0 указаны для каждого файла отдельно; у нескольких снимков Commons прямо указывает общественное достояние, что также сохранено в манифесте. Лицензия кода приложения их не заменяет. Фотографии уменьшены и преобразованы в JPEG, это отмечено в атрибуции.

## Где видны

- В уроках A1–A2 с подходящими английскими примерами: до четырёх фото в объяснении и до двух в задании.
- В минимальных парах: ship/sheep, bed/bad, bag/back, wine/vine, tree/three. `bad` показано через испорченное яблоко: при прослушивании звучит именно bad.
- В словаре и быстрой практике: фото выбирается по существительному и русскому значению контекста. Для ship в смысле «выпустить программу» корабль не подставляется.
- В статье слова под снимком стоит короткая подпись по-русски: например, laptop — «ноутбук». Формы вроде laptops и socks используют тот же предмет. Снимок готовой курицы показывается только в контексте еды.
- У фото доступны автор, лицензия и ссылки. При сохранении контекстной карточки источник переносится в примечание.

Тексты уроков, порядок и хэши курса не менялись. Если нужен снимок для конкретного урока вне A1–A2, добавь его ключ в `minimalPairs` манифеста или расширь привязку в `word-images.js`. Сам текст через этот механизм не переписывается.

Отдельные иллюстрации ситуаций в уроках описаны в [LESSON-IMAGES.md](LESSON-IMAGES.md). Они не смешиваются с найденными фотографиями слов.

## Добавить фото через Openverse

Скрипт отделяет поиск от выбранной фотографии. Для него нужен Pillow в отдельном Python-окружении:

```sh
python3.12 -m venv app/data/word-image-tools
app/data/word-image-tools/bin/python -m pip install Pillow
app/data/word-image-tools/bin/python app/scripts/fetch_word_images.py search spoon --query "spoon utensil" --ru "ложка"
```

На Windows вместо `bin/python` используй `Scripts/python.exe`. Кандидаты сохраняются в `app/data/word-image-candidates/spoon/`: `candidate-0.source`, `candidate-1.source` и т. д. Это исходные растровые изображения; их можно открыть просмотрщиком. Номера, авторы и ссылки также выведены в консоль и записаны в `candidates.json`.

Посмотри кандидатов, проверь страницу источника и лицензию. Выбери понятное фото без двусмысленного предмета, надписей и лишних деталей. Затем:

```sh
app/data/word-image-tools/bin/python app/scripts/fetch_word_images.py choose spoon 0 --reviewed --meaning-stems "ложк" --ipa "/spuːn/"
```

Опубликованы JPEG и атрибуция. Уже существующие фото сохраняются; для намеренной замены есть `--replace`. Для многозначных слов задавай точные `meaningStems`. Не используй общие фрагменты вроде «хорош» или «дел».

При добавлении минимальной пары укажи два ключа подряд в `minimalPairs` для нужного lesson ID. Сохраняй порядок пары: короткий звук, длинный звук. Послушай обе кнопки. Открой урок и словарный контекст, чтобы проверить связь картинки со смыслом. Содержимое уроков не трогай; при необходимости править их используй обычный `apply_course_rewrites.py` по правилам курса.

## Готовый промпт для следующего набора

> Дополни готовый курс английского реальными фото для слов A1–A2. Не переписывай уроки и не генерируй изображения. Сначала прочитай английские примеры и выбери конкретные предметные значения, которые ещё не представлены в app/studio/assets/words/manifest.json. Найди 3–6 кандидатов через Openverse или Wikimedia Commons. Допустимы CC0, CC BY и CC BY-SA с проверенной атрибуцией. Проверь исходную страницу каждого выбранного снимка и его лицензию. Визуально выбери фото: один ясный предмет, без двусмысленности и надписей, весь предмет помещается в кадр. Сохрани JPEG до 960 px без обрезания в assets/words; в манифест добавь автора, название, лицензию и URL лицензии, страницу источника, прямую ссылку, дату, описание преобразования и SHA-256. Подбирай фото по смыслу: ship — корабль, а не выпуск программы; orange — фрукт, а не цвет. Для минимальных пар подбирай обе картинки. Подключай фото в существующие уроки, словарь и карточки через word-images.js. Интерфейс минимальный, без курсива, оранжевых плашек и обрезанного текста. Сохрани полную атрибуцию. Не запускай тесты или линтеры и не коммить без разрешения.

Источники: [Openverse API](https://api.openverse.org/v1/), [правила атрибуции Commons](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia). Конкретные страницы и лицензии находятся в манифесте рядом с каждым фото.
