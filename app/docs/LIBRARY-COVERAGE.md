# Полное покрытие локальной библиотеки

Аудит выполнен 9 сентября 2026 года по всем 11 PDF из папки `книги`.

Базовый каталог этого аудита содержит **1 017 записей юнитов, 872 уникальные главы из 10 разных учебников**. Ещё один PDF — электронная версия уже имеющегося Murphy: её 145 глав не прибавляются повторно. Слово «уникальные» относится к главам и изданиям, а не к непересекающимся языковым темам.

Состояние текущего выпуска: базовые 872 главы опубликованы. [Отдельное дополнение из 59 глав](NEW-COURSEBOOKS-SOURCE-INTAKE.md) готовится к выпуску; после его полной публикации будет 931 книжная глава. Ниже сохранена сверка исходных 11 PDF. Актуальные числители готовности берутся из `content/book-release.json` и `/api/library/status`, а 163 основных занятия и 22 необязательных обзора считаются в [авторском маршруте](ONE-PROGRESSIVE-COURSE.md) отдельно.

Это полный каталог нумерованных учебных юнитов, а не прежняя выборка из 208 тем. Справочные приложения, ключи к упражнениям, индексы и дополнительные тесты не выдаются за новые учебные юниты. ## Исправления прежнего представления библиотеки

- В Intermediate Phrasal Verbs **70**, а не 60 юнитов. Включены, среди прочего, mobile devices, computers, American and Australian phrasal verbs и academic writing.
- Файл `Murphy-Essential-Grammar in Use Intermediate-2015.pdf` назван неверно: внутри **English Grammar in Use**, а не Essential. Его imprint прямо указывает печатную публикацию 2012 года и электронную публикацию 2015 года. Последовательность всех 145 тем и содержимое каждого двухстраничного юнита сопоставлены с PDF 2012 года.
- В Essential нет стандартной страницы Contents: восстановлены все 115 названий по самим юнитам.
- В обеих Vocabulary Advanced и Upper-intermediate по **101** юниту.
- Названия сохранены на английском, без замены темы рекламным описанием. Пробелы, регистр ошибочного OCR и типографические разделители нормализованы.

## Проверка страниц

`app/content/toc/catalog-page-verification.json` содержит отдельную запись проверки для каждого из 1 017 юнитов:

- 700 заголовков найдены непосредственно в текстовом слое соответствующих страниц.
- 164 заголовка сканов совпали после OCR верхней части страницы.
- 6 неоднозначных результатов OCR проверены по изображениям заголовков: Hewings 23, 70, 76, 83, 96, 97. В unit70 само оглавление использует *Adjectives*, а заголовок урока — *Adjective*; каталог сохраняет название из оглавления.
- 145 юнитов Murphy2012 сопоставлены с содержимым тех же юнитов ebook2015. У печатного PDF OCR пропускает цветные полосы с заголовками. Для каждого юнита совпадение проверено также против соседних юнитов: наиболее близок именно соответствующий.
- 2 многострочных заголовка проверены с учётом порядка текста в PDF: Essential102 и Vocabulary Upper-intermediate85.

У `page` нумерация **с единицы по PDF**, а не печатный номер внизу страницы. `endPage` указывает включительно вторую страницу юнита. Поэтому ссылки `/books/<filename>#page=<page>` открывают нужный разворот.

## Файлы и воспроизведение

- `app/content/library.json` — метаданные, полные оглавления, проверенные страницы, связь дубликатов. Полного текста книг здесь нет.
- `app/content/toc/catalog-manual.json` — вручную сверенные названия из сложных оглавлений.
- `app/content/toc/catalog-essential-titles.txt` — все 115 заголовков Essential.
- `app/content/toc/catalog-pages/*.json` — извлечённые страницы оглавлений и манифест исходных файлов.
- `app/data/library-text.json` — локальный текстовый кеш юнитов для чтения и работы с преподавателем. Папка `app/data` уже исключена из Git.
- `app/data/catalog-verify` — локальные материалы проверки: полосы заголовков сканов, OCR и короткие заголовки PDF.

Старый кеш оглавлений содержит 847 записей с текстовым слоем и 170 записей `source: "scanned"` с пустым `text`. Это историческое состояние кеша, не состояние готовых уроков. Для книжного выпуска страницы сканов впоследствии были обработаны отдельно с изображениями и проверкой источника; опубликованные главы используют `data/parsed-books/`, а переносимый выпуск подтверждает `content/book-release.json`.

Для обновления каталога по той же библиотеке последовательно запустить в Python с пакетами `pypdf`, `pypdfium2`, Pillow:

```text
python app/scripts/catalog_extract.py
python app/scripts/catalog_headers.py
python app/scripts/catalog_build.py
python app/scripts/catalog_text.py
python app/scripts/catalog_scans.py
powershell -NoProfile -ExecutionPolicy Bypass -File app/scripts/catalog_ocr.ps1
python app/scripts/catalog_validate.py
```

Скрипты ничего не загружают из интернета, не изменяют исходные PDF и не публикуют книги. После добавления другой редакции или новой книги нужны сверка её оглавления и обновление определения книги; старая нумерация не переносится на неё автоматически.
