# Whisper и озвучка: Mac и Windows

Уроки остаются готовыми: их текст и хэши не менялись. Распознавание подключается отдельно, а кнопки «Послушать» используют существующий Kokoro с четырьмя американскими голосами.

## Mac

Нужны Go 1.25+, Python 3.12+ и инструменты Apple:

```sh
xcode-select --install
brew install go python@3.12
bash Install-Speech.command
bash Start-English.command
```

Команды выполняются из корня репозитория. После первой установки `.command` можно открывать двойным щелчком. Если macOS блокирует файл, используй Terminal. CMake установщик найдёт сам или установит в отдельное окружение. Apple Silicon автоматически использует Metal. На Intel выбран CPU; скорость зависит от процессора. Kokoro использует ONNX Runtime на CPU.

По умолчанию скачивается английская модель `small.en-q5_1` (около 190 МБ). У Kokoro модель и голоса занимают ещё около 353 МБ. На слабом компьютере можно выбрать меньшую модель:

```sh
bash Install-Speech.command --model base.en
```

Whisper собирается из закреплённого коммита whisper.cpp v1.9.5. У моделей проверяется SHA-256. Установщик ничего не удаляет из чужого Whisper и не завершает процессы.

## Windows и CUDA

Установи Go 1.25+, Python 3.12+ и Visual Studio Build Tools с компонентом **Desktop development with C++**. Для NVIDIA добавь CUDA Toolkit: команда `nvcc --version` должна работать. Открой **Developer PowerShell for VS**, перейди в корень репозитория и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File app/scripts/install-local-whisper.ps1 -Accelerator cuda
powershell -ExecutionPolicy Bypass -File app/scripts/install-local-kokoro.ps1
```

Открой `Start-English.cmd`. Для CPU замени `cuda` на `cpu`. Для автоматического выбора можно оставить `auto`: при наличии nvcc выбирается CUDA. Драйвер NVIDIA без CUDA Toolkit недостаточен для сборки. Python можно передать явно: `-PythonPath C:\Python312\python.exe`.

Старый CPU Whisper сохраняет поддержку запуска. Для вероятностей слов нужен новый сервер; обновлённый установщик собирает его отдельно в `app/data/local-whisper/source`.

## Уже скачанный Whisper

Запусти свой свежий whisper.cpp server с английской моделью:

```sh
whisper-server --host 127.0.0.1 --port 8080 --model /path/to/ggml-small.en-q5_1.bin --language en
```

В Windows используй путь к `whisper-server.exe` и модели. В настройках приложения укажи `http://127.0.0.1:8080/inference` и нажми **Проверить Whisper**. Адрес `http://127.0.0.1:8080` также подходит. Проверка обращается к `/health`, не отправляя запись.

Для запуска своего бинарника через Mac-лаунчер:

```sh
WHISPER_SERVER=/path/to/whisper-server WHISPER_MODEL=/path/to/model.bin bash Start-English.command
```

`faster-whisper` как Python-библиотека сам по себе не даёт HTTP-адрес. Эта установка использует whisper.cpp. Ответ совместимого сервера `/v1/audio/transcriptions` с массивом `words` также читается, но health endpoint должен возвращать `{"status":"ok"}`; запуск такого сервера здесь не устанавливается.

## Что делает разбор

В speak-заданиях, произношении и шаге «поговорить» есть раскрывающийся блок **Повторить образец и проверить слова**. Сначала можно послушать образец, затем записать повторение. Сравнение по словам показывает пропуски, замены и лишние слова; регистр, пунктуация и распространённые стяжения вроде `I'm` не считаются ошибкой. Низкая уверенность ниже 0,65 отмечается как **проверь произношение**. Есть короткие русские подсказки для th, w/v, ship/sheep, bed/bad, конечных звонких согласных, -s и -ed.

Свободная речь расшифровывается без требования повторить один образец. В дневном пересказе расшифровывается каждый круг; разбор прошлого круга не заменяет текущий.

Вероятность — уверенность распознавателя, а не балл произношения. Тихая запись, шум и необычное слово тоже снижают её. Whisper не проверяет каждый фонемный звук и не даёт надёжной оценки акцента или интонации. Если старый сервер вернул только текст, сравнение работает, а вероятности не выдумываются. Эталон не передаётся Whisper как подсказка, чтобы не подталкивать его к «правильному» ответу.

## Адреса и файлы

- Приложение: `http://127.0.0.1:8790`; при ручном `go run ./cmd/english` по умолчанию порт 8777.
- Whisper: `127.0.0.1:8080`; Kokoro: `127.0.0.1:8880`.
- Лаунчер заполняет пустое поле Whisper через API только после готовности сервера. Уже выбранный адрес сохраняется.
- Модели, окружения, бинарники, журналы и PID находятся в игнорируемой Git папке `app/data/`.
- Журналы: `app/data/local-whisper/server.stderr.log`, `app/data/local-kokoro/server.stderr.log`, на Mac также `app/data/launcher/english.stderr.log`.

При конфликте портов работающие процессы не завершаются. Дождись загрузки модели или выбери адрес уже работающего сервера в настройках. Для записи разреши микрофон браузеру. Фото и установленные модели доступны без интернета; выбранный ИИ-помощник или браузерное распознавание могут использовать сеть.

## Что проверено

На Mac с Apple M1 Max реально запущены Whisper с Metal, Kokoro и Go-приложение. Озвученная английская фраза отправлена в Whisper через API приложения: получены слова, временные отметки и вероятности. Интерфейс проверен в браузере. Автоматические тесты и линтеры не запускались по просьбе пользователя. Windows CUDA и Intel Mac подготовлены в скриптах, но на их оборудовании запуск не проверялся. Новая запись с живого микрофона пользователя не выполнялась.

Источники: [whisper.cpp](https://github.com/ggml-org/whisper.cpp), [HTTP-сервер](https://github.com/ggml-org/whisper.cpp/tree/master/examples/server), [закреплённый выпуск](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.5), [Kokoro ONNX](https://github.com/thewh1teagle/kokoro-onnx).

## Общий Whisper со speech-learning

На этом Mac у проекта speech-learning уже запущен многоязычный Whisper на `http://127.0.0.1:8178/inference`. В English можно указать этот адрес в настройках: английская речь распознаётся и этим сервером, со словами и временными отметками. Тогда portable-лаунчер English не запускает ещё одну локальную модель. Общий сервер нужно запустить через speech-learning; его процессы и файлы English не меняет. Собственная английская модель English остаётся доступна на порту 8080. Для неё верни адрес `http://127.0.0.1:8080/inference`.

## ChatGPT после распознавания

Выбери «Мой аккаунт ChatGPT · Codex» в настройках. Кнопка «Проверить вход ChatGPT» проверяет авторизацию без запроса к модели. Если входа нет, на Mac открой `Connect-ChatGPT.command` или выполни `codex login` в Terminal / PowerShell; вход завершается в браузере. Затем «Проверить подключение» отправляет короткий запрос к модели. Ручной токен аккаунта не нужен.

Расшифровка, свой ответ и контекст упражнения передаются помощнику для проверки языка и диалога. Аудио обрабатывает локальный Whisper. Успешный вход сам по себе не гарантирует свободный лимит или доступ к любой модели. [Официальная инструкция OpenAI](https://learn.chatgpt.com/docs/auth).

На этом Mac вход ChatGPT обнаружен, выбран Codex и выполнен реальный короткий запрос через API приложения: модель вернула «Подключение работает». Тестовые наборы и линтеры не запускались.
