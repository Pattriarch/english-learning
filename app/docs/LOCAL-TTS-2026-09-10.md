# Kokoro вместо системной озвучки

10 сентября 2026 года основная озвучка приложения заменена на локальную нейросетевую Kokoro. В настройках можно сравнить четыре американских голоса на одинаковом тексте: Heart и Bella — женские, Michael и Fenrir — мужские. По умолчанию выбран Heart. Для явно выбранного британского сравнения в произношении используется Emma.

## Выбор решения

Проверены первичные материалы [Kokoro ONNX](https://github.com/thewh1teagle/kokoro-onnx), [Chatterbox](https://github.com/resemble-ai/chatterbox), [Piper](https://github.com/OHF-Voice/piper1-gpl) и [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS). Для этого приложения выбран Kokoro ONNX: готовые американские голоса, компактные веса и возможность постоянно держать модель на CPU. Это инженерный выбор по сложности установки и измеренной скорости, не утверждение о победе в независимом сравнении качества.

| Решение | Что проверено | Вывод для приложения |
|---|---|---|
| Kokoro ONNX | 82M; код MIT, модель Apache 2.0; есть готовые US-голоса | Установлено и проверено на этом Windows-компьютере |
| Chatterbox | MIT; актуальные Turbo/Nano и штатные голосовые conditioning-файлы | Более тяжёлый комплект; локальная установка и сравнение качества здесь не проводились |
| Piper | GPL-3.0; Windows wheels, компактные модели и HTTP server | Подходит для простой CPU-озвучки; не выбран без субъективного сравнения голосов |
| Qwen3-TTS CustomVoice | 0.6B/1.7B; встроенные голоса, включая американский Aiden; Apache 2.0 | Возможный следующий кандидат; требует более тяжёлого стека, на этой машине не тестировался |

[Официальная таблица Kokoro](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md) относит Heart к наиболее качественным голосам по авторской оценке обучающих данных. Она также предупреждает о слабости очень коротких реплик и ускорении длинных. Эти оценки не являются гарантией корректного произношения конкретного слова.

## Работа в приложении

Все кнопки синтеза в тетради, словаре, карточках, книжных юнитах, материалах уроков и произношении используют общий `POST /api/speech`. Браузер больше не выбирает Zira или другой системный голос автоматически. Старые заранее созданные WAV остаются на диске, но эти кнопки их не воспроизводят. Речь из исходного видео и собственные записи пользователя сохраняют оригинальный звук.

Модель постоянно работает на `127.0.0.1:8880`; браузер обращается только к основному Go-серверу приложения. `Start-English.cmd` запускает Kokoro и проверяет его готовность. При отсутствии сервиса интерфейс сообщает об ошибке, без незаметного возврата к системному голосу. После установки для синтеза не нужны платные API или интернет.

Выбор голоса записывается отдельно в `app/data/studio/speech-settings.json`. Основные настройки помощника, API-ключ и учебный прогресс этот endpoint не меняет. Кеш состоит из `speech-cache/*.json` и `media/*.wav` внутри профиля. Его идентификатор учитывает модель/версию, голос, акцент и полный текст. Смена голоса создаёт собственную запись; повторное прослушивание использует готовый файл. Изменение алгоритма синтеза в будущем требует обновления `kokoroCacheVersion`.

Ограничения: текст до 64 KiB UTF-8, WAV до 32 MiB, два одновременно принятых запроса и один активный синтез на CPU. Длинный текст делится на части с сохранением слов и пунктуации; аудио собирается целиком и не публикуется частично. Очень длинные непрерывные токены отклоняются. «Остановить» отменяет запрос; текущая нативная операция модели может закончиться, но следующие части уже не синтезируются.

## Установка после клонирования

Из корня репозитория, с Python 3.12:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\app\scripts\install-local-kokoro.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\app\scripts\start-local-kokoro.ps1
```

Если Python не находится автоматически, передайте установщику `-PythonPath` с путём к `python.exe`. Он создаёт отдельный venv и устанавливает закреплённые версии из `kokoro-requirements.txt`. Весам нужно около 354 MB, дополнительное место занимают зависимости. Все скачанные файлы и окружение находятся в игнорируемой Git папке `app/data/local-kokoro`.

Файлы получены из [релиза kokoro-onnx model-files-v1.0](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0):

| Файл | Размер, bytes | Закреплённый SHA-256 |
|---|---:|---|
| `kokoro-v1.0.onnx` (FP32) | 325532387 | `7d5df8ecf7d4b1878015a32686053fd0eebe2bc377234608764cc0ef3636a6c5` |
| `voices-v1.0.bin` | 28214398 | `bca610b8308e8d99f32e6fe4197e7ec01679264efed0cac9140fe9c29f1fbf7d` |

Это локально вычисленные хеши скачанных файлов из указанного релиза; GitHub API для этих старых assets не предоставил собственный digest. Установщик сверяет размер и хеш при повторных установках. Runtime — `kokoro-onnx 0.6.1`, ONNX Runtime CPU 1.29.0, фонемизация eSpeak `en-us`/`en-gb`. Видеокарта не используется. Совместимость с кириллицей в Windows-пути проверена; для нативного eSpeak добавлен узкий адаптер короткого пути после нормализации пути в phonemizer 3.4.

## Фактические проверки

На i5-12400F, шесть потоков CPU, после прогрева:

| Пример | Подготовка | Длина WAV |
|---|---:|---:|
| Heart, три разговорных предложения | 2.84 s | 9.94 s |
| Bella, тот же текст | 3.01 s | 10.37 s |
| Michael, тот же текст | 3.15 s | 10.75 s |
| Fenrir, тот же текст | 3.03 s | 10.37 s |
| Отдельное слово, Heart | 0.40 s | 0.88 s |
| Материал extended-b2-sleep/m1, 299 слов, Michael | 34.35 s | 119.57 s |

Повторный запрос материала вернул тот же WAV за 0.01 s. Результаты относятся к этим текстам и этому компьютеру, не являются обещанием постоянной задержки.

В настоящем интерфейсе проверены прослушивание Heart и Michael, сохранение Michael после перезагрузки, его применение в книжном уроке и отдельном слове курса произношения. Проверены PCM mono 24 kHz, разные файлы для разных голосов и кеш. Контроль через Whisper распознал основной текст и короткие пары; были расхождения токенизации `I'll`/`workaround`, а отдельное `Apartment` распознано как `Apartments`. Поэтому этот контроль не выдается за экспертную проверку произношения или субъективную оценку естественности.

Автоматические проверки: полный Go suite и `go vet` прошли, JavaScript — 185 тестов, Python-сервис — 19 тестов. Включены отмена при смене страницы/голоса, поздние ответы, сохранность ручного текста, разрыв TCP, освобождение слотов, ограничения размера, отсутствие потери слов между частями, отсутствие системного fallback и раздельный кеш US/GB. Go `-race` не запускался: в текущем окружении нет настроенного CGO-компилятора; обычные конкурентные проверки прошли.
