# Полные разборы контекстного словаря

Цель выпуска — подробное учебное пояснение **каждого активного примера** во всех трёх словарных банках. Исходная контрольная точка содержит 10 987 статей (10 951 слово и 36 выражений), 18 534 активных контекста. Это не обещание перечислить все существующие значения каждого английского слова.

В каждом подготовленном контексте есть:

- точное значение выделенного употребления и перевод всего предложения;
- объяснение на русском: что выражает слово, почему подходит здесь и как его применять;
- 2–4 пояснения о конструкции, сочетаемости, грамматике или регистре;
- 2–4 английских сочетания с русскими переводами;
- 1–2 конкретные ошибки или смысловые несоответствия с исправлением и объяснением;
- самостоятельное задание: написать адресное сообщение из 2–3 предложений в новой ситуации.

Основной вариант — американский английский. Разговорная и грубая лексика сохраняется с пояснением уместности. Корректная британская форма не объявляется грамматической ошибкой; при замене учебного примера региональная причина указана отдельно.

## Подготовка и проверка

`scripts/enrich_lexicon.py` фиксирует точные исходные банки и каждый активный контекст. Для черновика и отдельной содержательной проверки вызывается существующий авторизованный CLI, без доступа модели к командной строке, браузеру и инструментам. Исправление проверяется новым запросом; сам факт наличия поля или контрольной суммы не считается проверкой смысла.

Рабочие данные и полные доказательства запросов находятся локально в `app/data/lexicon-full-analysis/`. Они содержат `input.json`, пакеты `batches/NNNN/`, точные запросы, ответы проверок, `verified.json` и состояние обработки `run-status.json`. Пакеты можно продолжать после перезапуска. Ограничение провайдера прекращает запуск новых пакетов; скрипт не покупает доступ и не использует сброс лимита.

Исходные `entries.json`, `coca-extension.json` и `american-phrases.json` не переписываются. Проверенные пояснения публикуются отдельными неизменяемыми JSON-файлами с контрольными суммами. `content/lexicon/full-analysis.json` атомарно указывает актуальный набор; `complete: true` допустимо только после проверки всех 18 534 исходных активных контекстов. Промежуточный выпуск явно содержит `complete: false` и фактический счётчик. Неиспользуемые старые фрагменты не являются дополнительными словарными статьями.

При сохранении исходного примера его английский текст и идентификатор остаются прежними. Неподходящий исходный пример сохраняется в архиве источника, а новая американская ситуация получает новый идентификатор. Непроверенные замечания старого источника не переносятся в новую ситуацию автоматически.

## Использование

Откройте «Живой словарь», выберите пример и изучите разбор. Затем включите «Проверить себя без подсказок»: английский пример, дополнительные значения, пояснения и озвучка скрываются. Напишите собственное сообщение и отправьте его на проверку. Можно ответить голосом; разбор расшифровки не измеряет произношение.

«Сохранить контекст в повторение» переносит русский смысл, английский пример и пояснения в карточку. Отметка «узнаю в контексте» остаётся самооценкой; собственные ответы и обратная связь хранятся отдельно. Обновление пояснений меняет отпечаток задания, поэтому старая проверка не выдаётся за оценку новой формулировки.

Личный прогресс сохраняется в `app/data/studio/progress.json`, записи — рядом в `media/`. Подготовка словаря этот файл не изменяет. Репозиторий содержит код и выпущенные разборы; личные ответы, исходные книги и рабочие материалы исключены из Git.

## Команды для сопровождения

```powershell
python app/scripts/enrich_lexicon.py --status
python app/scripts/enrich_lexicon.py --generate --workers 4 --timeout 2400 --publish-every 8
python app/scripts/enrich_lexicon.py --publish
python -m unittest discover -s app/scripts -p test_enrich_lexicon.py
```

Не запускайте два координатора одновременно. Полная публикация отказывается пропускать незавершённые пакеты или терять уже опубликованные контексты. Значения `rows`, `targetRows` и `complete` в манифесте — актуальный источник состояния выпуска; число файлов и наличие черновиков его не заменяют.

Для большого остатка выпуска используется GPT-5.6 Sol для новых черновиков и GPT-6 Astra для независимой проверки. Модель задаётся только конкретному запуску, без изменения настроек пользователя:

```powershell
python app/scripts/enrich_lexicon.py --generate --workers 16 --timeout 2400 --publish-every 8 --model gpt-5.6-sol --review-model gpt-6-astra
```

Выбор проверен на отдельной выборке из 12 контекстов, включая многозначные слова, разговорную и формальную лексику. Независимая проверка выявила ошибочную помету редкого союзного употребления `notwithstanding`; подтверждённые ранее разборы при смене автора не перезаписываются. Это проверка процесса, а не доказательство безошибочности всего словаря. Разделение автора и проверяющего также уменьшает расход общего лимита; актуальные правила описаны в [официальной документации](https://learn.chatgpt.com/docs/pricing).

Для остановки без потери выполняемых пакетов создайте `app/data/lexicon-full-analysis/pause-request.json` с содержимым `{}`. Координатор завершит начатые пакеты, опубликует проверенное и выставит `state: paused`. Перед следующим запуском уберите этот сигнал. Дождитесь завершения координатора перед правкой квитанций или запуском второго процесса. При технически неполном исправлении проверяющего скрипт ремонтирует только затронутое предложение и отправляет его на новую содержательную проверку; структурная проверка сама по себе не означает принятие содержания.

## Исправления после выборочной проверки

Отдельная выборка из 32 опубликованных контекстов выявила одну ошибку классификации: инфинитивное `to` было отнесено к conjunction. В расширенной схеме для него предусмотрено `infinitive-marker`; такое отдельное описание используется и в [Oxford Advanced American Dictionary](https://www.oxfordlearnersdictionaries.com/definition/american_english/to_2). Предложение о причине ошибки в схеме не должно попадать в учебное объяснение.

`scripts/amend_lexicon_analysis.py` принимает очередь адресных исправлений с контрольной суммой прежнего принятого разбора. Каждое исправление получает отдельную содержательную проверку; изменения проверяющего снова проверяются. Исходная квитанция сохраняется в истории, прежние запросы не переписываются под новую схему. Скрипт отказывается редактировать квитанции работающего массового координатора. Запуск после его завершения:

```powershell
python app/scripts/amend_lexicon_analysis.py --queue app/data/lexicon-full-analysis/editorial-queue.json --publish
```

Выборка помогает находить дефекты процесса, но не выдаётся за ручную экспертизу всех 18 534 контекстов.
