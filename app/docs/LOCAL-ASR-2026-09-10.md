# Локальное распознавание английской речи

Проверено 10 сентября 2026 года на Windows: whisper.cpp работает на CPU, слушает только `127.0.0.1:8080`, а приложение передаёт ему WAV через `/api/transcribe`. Платные ключи для распознавания не нужны. Во встроенном браузере этой установки `SpeechRecognition` и `webkitSpeechRecognition` отсутствуют, поэтому настроенный локальный сервер обеспечивает расшифровку после остановки записи.

## Установка после клонирования

Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\app\scripts\install-local-whisper.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\app\scripts\start-local-whisper.ps1 -ForceStart
```

В настройках приложения сохраните адрес Whisper `http://127.0.0.1:8080/inference`. Обычный `Start-English.ps1` затем проверяет и запускает этот сервис перед запуском приложения. Установщик сам не меняет настройки приложения. `-ForceStart` нужен для первого запуска до сохранения адреса; при обычном запуске helper проверяет настройку `whisperUrl`.

Установщик скачивает около 156 MB, проверяет размер и SHA-256 обоих файлов и безопасные пути ZIP до распаковки. Повторный запуск использует проверенные существующие файлы. Модель, бинарники, логи и локальные квитанции находятся в игнорируемой Git папке `app/data/local-whisper`; в репозиторий входят только скрипты и эта инструкция. Перенос модели в Git не требуется.

## Запуск и настройки

Сервис стартует скрытым процессом Windows с `--host 127.0.0.1 --port 8080 --model ggml-base.en.bin --language en --threads 6 --no-gpu`. Относительный путь модели и рабочая папка помогают избежать проблем с кириллицей в имени учётной записи. Пустая папка `public` ограничивает раздаваемое статическое содержимое; приложение обращается к API сервера.

Helper использует файловую блокировку, повторно использует уже работающий экземпляр из ожидаемого пути и проверяет `/health`. Если порт занят чужим процессом или слушает внешний интерфейс, helper сообщает ошибку и никого не завершает. Ошибка необязательного speech helper не мешает открыть само приложение. Логи: `app/data/local-whisper/server.stdout.log` и `server.stderr.log`; сведения о проверенном процессе: `server-state.json`.

На этой машине URL сохранён через API настроек. Полное сравнение объектов настроек до и после в памяти подтвердило, что изменился только `whisperUrl`: провайдер, модель, endpoint и ключ сохранены. Ключи не выводились в отчёт или логи проверки. Установщик не добавляет платный AI-провайдер: настройка проверки свободного ответа остаётся отдельной от распознавания.

## Фактическая проверка

Создана отдельная синтетическая запись Microsoft Zira Desktop, `en-US`: PCM WAV, 16 kHz, mono, 16 bit, 294,286 bytes, около 9.2 секунды. Микрофон пользователя не включался. Текст:

> I usually work from home, but today I'm helping my team test a new application. We should check the results before we send the report.

SHA-256 WAV: `4dc0bd02720575c41e609680216b71a6115d2f2200864157035a5ba24e40d0b7`.

При повторной проверке после обновления основного приложения в 16:17 UTC:

| Путь | Результат | Время ответа |
|---|---|---:|
| WAV → `127.0.0.1:8080/inference` | Все 25 слов в правильном порядке | 0.946 s |
| WAV → `127.0.0.1:8777/api/transcribe` → Whisper | Все 25 слов в правильном порядке | 0.788 s |

Сравнение игнорировало регистр и пунктуацию; переносы строк в результате отличались. Эти цифры относятся к данному короткому файлу на CPU Intel i5-12400F и не являются обещанием скорости для любой записи. Локальные артефакты: `app/data/local-whisper/qa/{english-reference.wav,expected.txt,direct-result.json,app-result.json,verification.json}`.

PowerShell-скрипты прошли синтаксическую проверку. Повторный старт сохранил один процесс. Дополнительно проверена именно ветка распаковки установщика в отдельной игнорируемой QA-папке: исходные проверенные ZIP/модель подключены hardlink, пакет распакован, извлечённый CPU executable успешно выполнил `--help`. Второй сервер при этой проверке не запускался.

## Границы проверки

Проверены установка, старт и путь реального аудиофайла через API приложения. Захват пользовательского микрофона, разрешение браузера и качество распознавания конкретного акцента этой синтетической проверкой не подтверждаются. Запись в браузере по-прежнему требует разрешения пользователя.

Whisper выдаёт текст и может ошибаться при шуме, тишине, сильном акценте или редких именах. Это не фонетический экзамен: совпадение расшифровки не доказывает правильное произношение каждого звука. Пользователь видит расшифровку и может исправить её; существующая проверка английского ответа анализирует полученный текст. Модель `base.en` выбрана для английской речи и умеренных требований к CPU/диску.
