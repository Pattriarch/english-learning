# Сохранение собственных мыслей и записей: проверка 10 сентября

Исправлены пять обнаруженных ошибок в `studio/notebook.js` и минимально расширен `studio/audio.js`:

1. Перевод получает русскую мысль, контекст и стиль, зафиксированные до первого ожидания сохранения. Поздние правки не подставляются в запрос с отпечатком прежнего текста.
2. Проверка собственного английского ответа фиксирует ID, режим, текст, вопрос и контекст до ожидания. Ответ прежней версии не сбрасывает ID новой версии. У восстановления мысли и отдельного применения разные idempotency ID даже при одновременной отправке.
3. Отдельный флаг recording убран. Ошибка рекордера или остановка без данных освобождает реальное состояние кнопки, после чего запись можно начать снова.
4. `recordOnly(button, preview, onReady, {retainOnLeave:true})` передаёт Blob третьим аргументом callback, даже если экран уже закрыт. Notebook использует этот режим. Старые вызовы с тремя аргументами сохраняют поведение: несохраняемый preview после ухода отбрасывается. Неудачный recorder не публикует повреждённую запись.
5. Запись notebook существует до начала работы с микрофоном. После загрузки аудио сохраняется только отдельный `notebook:recording:<id>`, содержащий исходный entryId, текст, тип и время начала записи. Поздний upload не переписывает объект заметки из старого mount.

Дополнительно идентичность экрана проверяется по конкретному DOM-элементу редактора, а не только ID заметки: старый callback не рисует результат поверх заново открытой заметки с тем же ID.

## Размер и совместимость

Новые результаты хранят `source` как `sha256:<64 hex>` от UTF-8 JSON массива `[russian.trim(), context.trim(), register]`. SHA проверен на соответствие Node crypto с Unicode и границами блоков. Полный оригинальный текст заметки остаётся в entry; результат не содержит его вторую копию. Результаты старого формата, где source был исходным JSON, продолжают открываться и корректно распознаются как актуальные/устаревшие.

Backend сохраняет максимум13000 байт полного ответа перевода. Вместе с71-символьным fingerprint, version и датой результат помещается в19500-байтный draft. Содержимое не обрезается: превышение ограничения вызывает понятную ошибку. Отдельные тесты используют длинный перевод, который со старой копией исходника не помещался в draft.
