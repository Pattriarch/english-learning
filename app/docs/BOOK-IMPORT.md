# Полный разбор локальных учебников

Состояние системы на 10 сентября 2026 года: извлечение всех нумерованных юнитов завершено, подробные уроки продолжают готовиться фоновым пакетом. Число извлечённых страниц не равно числу готовых уроков. Актуальные числа показывает раздел «Все учебники».

## Что действительно прочитано из файлов

- 11 PDF, 10 разных учебников; 1017 записей по изданиям, 872 уникальных нумерованных юнита.
- 847 записей извлечены с учётом расположения текста. Для 145 юнитов Murphy повреждённый OCR основного PDF заменён чистым текстом эквивалентного ebook. Метаданные сохраняют оба источника и номера страниц.
- 170 юнитов двух сканированных книг распознаны целиком: 340 страниц. Сохраняются исходное распознавание, координаты слов и реконструированный порядок чтения.
- Для каждого уникального юнита подготовлены изображения обеих страниц: всего 1744 JPEG, 160 dpi. В пакет v2 передаются и текст, и изображения, в том числе таблицы, зачёркивания, схемы и иллюстрации.
- Вне нумерованных юнитов отдельно извлечены 28 приложений и справочных разделов, 177 страниц: грамматические сводки, неправильные глаголы, фонетические таблицы, мини-словари, диагностика и смешанное повторение. Они не увеличивают число подготовленных уроков.

Все страницы прошли техническую проверку полноты. Ручная визуальная вычитка выборочная: это не утверждение, что каждый символ всех книг проверен человеком. Известные ошибки OCR исправлялись по изображению, сомнительные фрагменты отмечены в `quality`. Источники не заменяют официальные ключи ответов: новые задания приложения имеют собственные эталонные ответы.

## Что получает ученик

Готовый юнит сразу открывает самостоятельный русский разбор содержания исходных страниц. В нём не менее четырёх подробных разделов, контрастные английские примеры с переводом и восемь заданий: полные переводы, переформулировки, свои тексты и устный ответ. Модель связывает каждую существенную тему источника с разделом урока; в v2 дополнительно описывает, что прочитано на каждой картинке.

Экран разделён на объяснение, практику и личный конспект. Оригинальный PDF доступен для сверки. Примеры можно отправить в карточки и прослушать. Для браузера без английского TTS локально создаются WAV голосом Microsoft Zira, en-US. Диктовка использует уже настроенные браузерное распознавание или Whisper; проверка текста не оценивает акустическое произношение.

Готовые уроки публикуются по одному, библиотека обновляет счётчики каждые 30 секунд. Ещё не готовый урок так и обозначается; общий шаблон заданий не выдаётся за его разбор. Первый текстовый вариант может оставаться доступным, пока готовится его более точный вариант по изображениям.

## Сохранение и обновление

Профиль пользователя остаётся в `app/data/studio/progress.json`, рядом предыдущая версия `.bak`. Черновики сначала записываются в браузер, затем на сервер. Разборы, ответы, карточки и отметки автоматически сохраняются в профиль. Учебные материалы хранятся отдельно от прогресса.

Идентификатор задания содержит отпечаток его формулировки, контекста, подсказки и эталонного разбора. Поэтому новая версия вопроса получает другой черновик и не наследует выполненность старого. Уже полученные разборы остаются в журнале со старой формулировкой. Если урок обновился прямо во время ответа, проверяется сохранённая версия вопроса.

Новый экран работает и с уже запущенным сервером: статические материалы доступны через `studio/book-content`, проверка использует его существующий протокол свободного ответа. При следующем обычном запуске из исходников новый Go backend сможет дополнительно проверять версию задания и хеши источников на сервере. Принудительный перезапуск основного процесса для переноса книг не потребовался.

## Файлы и контроль пакета

| Путь | Назначение |
| --- | --- |
| `app/content/book-lessons/` | Подготовленные самостоятельные уроки с provenance |
| `app/studio/book-content/` | Атомарно опубликованные копии для текущего приложения |
| `app/studio/book-content/status.json` | Доступность уроков: `ready`, `visualReady`, `running`, `failed` |
| `app/data/book-build-status.json` | Подробный статус обработки с изображениями |
| `app/data/book-build-vision.stdout.log` | Ход текущего пакета |
| `app/data/parsed-books/` | Извлечённые источники каждого юнита |
| `app/data/book-page-images/` | Изображения страниц для разбора |
| `app/content/book-supplements.json` | Индекс дополнительных разделов |
| `app/data/parsed-book-supplements/` | Источники приложений, таблиц и справочников |
| `app/data/book-audio-status.json` | Готовность локальных аудиообразцов |

`ready` в публичном статусе означает доступный проверенный урок; `visualReady` — урок, дополнительно обработанный с обеими картинками. В приватном статусе готовность относится к текущей версии пакета. Машинное соответствие хешам и структурная проверка не являются гарантией отсутствия всех педагогических ошибок.

Пакет выполняется локально в отдельном скрытом процессе, с четырьмя запросами одновременно через установленный и авторизованный Codex CLI. Он продолжает работу после завершения ответа ассистента, пока компьютер включён. Это не облачная задача и не запланированная автоматизация. После перезагрузки компьютера нужен запуск с `--resume`. На ограничении провайдера пакет приостанавливается; кредиты и сбросы автоматически не используются.

Полная генерация — длительная операция. Небольшие первые текстовые уроки занимали около 3–4 минут каждый; вариант с изображениями может занимать больше. Готовность следует проверять по фактическому статусу, а не по обещанному времени.

Для текущего пакета запущен `keep_book_build_awake.py`: он временно предотвращает автоматический сон Windows до завершения именно этого процесса. Экран может гаснуть; план электропитания не изменяется. После остановки пакета запрос снимается. Выключение компьютера или ручной сон всё равно прервут работу.

Из корня проекта, если предыдущий пакет уже остановлен:

```powershell
$bookPython = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
& $bookPython app/scripts/build_book_lessons.py --all --workers 4 --resume --require-images
```

Перед запуском можно проверить очередь без запросов модели:

```powershell
& $bookPython app/scripts/build_book_lessons.py --all --resume --require-images --dry-run
```

Озвучка новых примеров:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File app/scripts/prepare-book-audio.ps1 -Watch
```

Скрипты извлечения: `book_text_layout.py`, `book_ocr.py`, `book_supplements.py`; изображения — `render_book_pages.py`. Полные отчёты и диагностика лежат в игнорируемой Git папке `app/data`. Публикация в облако и автоматический Git push не настроены.
