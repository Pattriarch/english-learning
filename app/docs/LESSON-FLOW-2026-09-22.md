# First lesson and practice flow, September 22

The old opening repeated “am is needed” and identical support across adjacent
translations. It did not explain why a Russian speaker would need the verb,
and separate visual/theory panels interrupted the exercise flow.

The first lesson now begins with a scene and a Russian-language explanation:
Russian usually omits present-tense “быть” in descriptions; English retains be.
A verb can describe a state, not just an action. The contrast with I work
prevents the misleading rule “always put am after I.” Only I am is required
before starting; other forms are introduced immediately before their task.

The twelve tasks build: own state, another person, she, we, diagnose an error,
location, it for a known object, negation, question, contraction, a personal
statement, a two-part message. Repetition of language is intentional; duplicate
explanations and adjacent tasks that only substitute an adjective are removed.
All twelve task revisions were incremented; old attempts/drafts remain stored
under their original identities and cannot count as newly authored tasks.

## Sources actually consulted

- Existing Murphy Unit 1 materials and the repository’s elementary chapter.
- [British Council: Link verbs](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/link-verbs): description versus action; be as a main linking verb.
- [YouTube: Unit 1, am/is/are](https://www.youtube.com/watch?v=87LAZgZeuuY&t=28s): read the available Russian automatic transcript, especially 0:28–3:15. Useful comparison with Russian past/future “быть”. Automatic English transcriptions were garbled and not used as authoritative examples. Avoided its overgeneralization that Russian has no present-tense “быть”.
- [Reddit learner discussion](https://www.reddit.com/r/EnglishLearning/comments/f9i1g7/): identifies a real stumbling block—equating every verb with visible action or every use of be with “exist”. Community replies were checked against the grammar reference, not treated as a rulebook.

Lesson prose and scenarios are original, not copied transcripts or forum replies.
American English audio is retained. Basic be grammar is shared across the
standard American/British varieties; no British-only vocabulary was introduced.

## Interaction

Guided lesson entry opens an explanation before practice. An explicit practice
link resumes at the task; deep links keep drafts and feedback available.
Correct current responses advance after 1.1 seconds. Editing, leaving the route,
or interacting with the feedback cancels navigation. Partial/ungraded responses
stay open. Saved responses never cause automatic navigation on a return visit.
Listening remains available in feedback, with an explicit Continue button if
the learner pauses the transition. Previous/next controls sit with the single
progress strip. The final step opens actual results rather than another lesson.

Removed bottom duplicated counters, shortcut labels and generic note panels.
Intro, illustration, practice and heading use the same 800px reading column.

## Scope

The flow changes apply to authored course lessons. The first lesson’s prose and
tasks received the detailed editorial rewrite; this is not a claim that all
215 lessons or all reference-book chapters have received this second review.
